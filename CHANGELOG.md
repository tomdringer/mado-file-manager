# Changelog

All notable changes to mado-file-manager are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-10-29

### Added
- Initial release: file manager pixel plugin for Mado sidebar
- Collapsible file tree with folder expand/collapse
- File type icons with per-type colours using Nerd Font glyphs (HackNerdFontMono)
- Keyboard-driven rename, delete, new file, and new folder
- Workspace chdir tracking — tree root updates on workspace switch
- File open via MACT `open_file` action
